## Prerequisites

- Docker with the Compose plugin
- The environment variables from [Self hosting](/self-hosting/overview)

## Docker Compose

The repository ships `deploy/compose.scribase-mail.yml` with the web app,
Postgres and Redis, local volumes and memory limits (1.5 GB total).

1. Copy `.env.selfhost.example` to `deploy/.env` and fill in the values.
2. Build the image on the server (it is built from `docker/Dockerfile`):

```sh
docker compose -f deploy/compose.scribase-mail.yml --env-file deploy/.env build
```

3. Start it:

```sh
docker compose -f deploy/compose.scribase-mail.yml --env-file deploy/.env up -d
```

Database migrations run automatically when the web container starts. The app
listens on `127.0.0.1:3000`; put a reverse proxy with TLS in front of it.

## Standalone container

You can also run only the web container against your own Postgres and Redis:

```sh
docker run -d \
  -p 3000:3000 \
  -e NEXTAUTH_URL="https://mail.example.com" \
  -e NEXTAUTH_SECRET="<secret>" \
  -e DATABASE_URL="<postgres-url>" \
  -e REDIS_URL="<redis-url>" \
  -e OCI_REGION="eu-frankfurt-1" \
  -e OCI_TENANCY="<tenancy-ocid>" \
  -e OCI_USER="<user-ocid>" \
  -e OCI_FINGERPRINT="<fingerprint>" \
  -e OCI_PRIVATE_KEY="<pem>" \
  -e SMTP_HOST="smtp.email.eu-frankfurt-1.oci.oraclecloud.com" \
  -e SMTP_PORT="587" \
  -e SMTP_USER="<smtp-user>" \
  -e SMTP_PASS="<smtp-password>" \
  -e FROM_EMAIL="noreply@mail.example.com" \
  scribase-mail:latest
```
