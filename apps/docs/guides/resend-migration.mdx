## Overview

Scribase Mail exposes a Resend-compatible REST API at `https://mail-api.scribase.com`.
The official Resend SDKs (Node, Python, Go, PHP, Ruby, Rust, Java, .NET, Elixir)
all support a custom base URL, so migrating is usually a single environment variable
change with zero code changes.

---

## 1 minute migration

<Tabs>
  <Tab title="Node.js (Resend SDK)">
    Set the `RESEND_BASE_URL` environment variable before starting your app:

    ```bash
    RESEND_BASE_URL=https://mail-api.scribase.com node server.js
    ```

    Or pass it in the constructor:

    ```typescript
    import { Resend } from "resend";

    const resend = new Resend(process.env.RESEND_API_KEY, {
      baseUrl: "https://mail-api.scribase.com",
    });
    ```

    Your Scribase Mail API key starts with `sm_`.
  </Tab>
  <Tab title="Python (resend)">
    Set the `RESEND_API_URL` environment variable:

    ```bash
    export RESEND_API_KEY=sm_...
    export RESEND_API_URL=https://mail-api.scribase.com
    python app.py
    ```

    Or in code:

    ```python
    import resend

    resend.api_key = "sm_..."
    resend.api_url = "https://mail-api.scribase.com"
    ```
  </Tab>
  <Tab title="Go">
    ```go
    import "github.com/resend/resend-go/v2"

    client := resend.NewClient("sm_...", resend.WithBaseURL("https://mail-api.scribase.com"))
    ```
  </Tab>
  <Tab title="SMTP">
    Update your SMTP host from `smtp.resend.com` to `smtp.mail.scribase.com`.
    Port, TLS mode, and auth format (username: `scribase`, password: API key) are
    the same.

    | Setting | Resend | Scribase Mail |
    |---------|--------|---------------|
    | Host | `smtp.resend.com` | `smtp.mail.scribase.com` |
    | Ports | 25, 465, 587, 2465, 2587 | 465, 587, 2465, 2587 |
    | Username | `resend` | `scribase` |
    | Password | Resend API key | Scribase Mail API key |
  </Tab>
</Tabs>

## Differences and limitations

| Feature | Resend | Scribase Mail |
|---|---|---|
| Webhook signature format | Svix (`whsec_...`, `svix-signature` header) | Svix-compatible by default (`whsec_...`, `svix-id`/`svix-timestamp`/`svix-signature` headers), same algorithm as Resend/Svix — verify with the [Svix SDK](https://docs.svix.com/receiving/verifying-payloads/how) or your own Standard Webhooks implementation |
| Custom tracking subdomain | Supported | `PATCH /domains/{id}` with `tracking_subdomain` (one label, such as `links`). Open and click links in later mail use `https://links.yourdomain.com`. CNAME that host to the app host (`mail.scribase.com` on the hosted service) before you save the label. The label cannot be cleared. |
| Attachment `path` (URL) | Supported (server-side fetch) | Supported — the server fetches the URL (HTTPS only, 40 MB cap, SSRF-guarded against private/reserved IPs, no redirects) and attaches it, same as `content` |
| Inline images via `content_id` | Supported | Supported — set `content_id` on an attachment and reference it in your HTML as `<img src="cid:yourId">` |
| `topic_id` on send | Supported | Coming with Topics feature |
| Inboxes / received email | Supported | Supported — `GET /emails/received`, `GET /emails/received/{id}` (+ attachments), plus Scribase Mail extensions `POST /emails/received/{id}/reply` and `/forward` that Resend itself doesn't offer |
| OAuth for third-party apps | Supported | Coming soon |
| Dedicated IPs | Available as add-on | Available via OCI support request |

## Webhook migration

Resend and Scribase Mail both sign webhooks using the Svix / Standard Webhooks
format (`whsec_...` secret, `svix-id`/`svix-timestamp`/`svix-signature`
headers) — existing Resend webhook verification code works unchanged against
`POST /webhooks`-created endpoints. Scribase Mail also sends the equivalent
`webhook-id`/`webhook-timestamp`/`webhook-signature` headers side by side for
compatibility with any Standard Webhooks library that expects that naming.
See the [Webhooks guide](/guides/webhooks) for setup and event types.

## Environment variables reference

| Variable | Purpose |
|---|---|
| `RESEND_API_KEY` | API key — accepted by Scribase Mail compat layer |
| `SCRIBASE_MAIL_API_KEY` | Preferred env var for Scribase Mail (takes precedence) |
| `RESEND_BASE_URL` | Node SDK base URL override |
| `SCRIBASE_MAIL_BASE_URL` | CLI / MCP server base URL override |
| `RESEND_API_URL` | Python SDK base URL override |
