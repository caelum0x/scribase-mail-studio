# Security policy

Please do not open public issues for security problems.

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/caelum0x/scribase-mail-studio/security/advisories/new)
or by email to postmaster@scribase.com. Include the affected version or commit,
steps to reproduce and the impact you expect.

We aim to acknowledge reports within 3 business days and to ship a fix or
mitigation for confirmed high-severity issues within 14 days. The hosted
service at mail.scribase.com is patched first; self-hosters should follow
releases on this repository.

Issues that only affect upstream [useSend](https://github.com/usesend/useSend)
code we did not modify are also worth reporting upstream.
